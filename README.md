# Global E-Commerce Revenue & Performance Dashboard

An interactive Power BI dashboard that transforms raw e-commerce transaction data into a dark-mode executive view of revenue, orders, and customer performance across global markets.

<img width="1206" height="806" alt="Dashboard_Look" src="https://github.com/user-attachments/assets/4cadc2da-5db1-49d4-8d23-88372484f6c2" />

## Overview

This dashboard tracks **$641.24M in total revenue** across **500K orders**, giving stakeholders a single view of top-performing products, regional distribution, payment channel mix, and customer contribution — all filterable by quarter.

## Key Metrics

- **Total Revenue:** $641.24M
- **Total Orders:** 500K
- **Average Order Value:** $1.28K
- **Units Sold:** 2M

## Features

- **Regional Sales Distribution** — geographic performance mapping across major markets
- **Category & Channel Analysis** — revenue breakdown by product category and payment method
- **Top-N Insights** — top 5 products and top 5 customers by revenue
- **Time-Series Trend** — monthly revenue performance across the year
- **Interactive Filtering** — quarter slicer with cross-filtering across all visuals
- **Custom Dark Theme** — cohesive cyber/dark-mode visual design across all charts

## Tools & Techniques

| Area | Details |
|---|---|
| Data Modeling | Power Query for data cleaning, type conversion, and a custom Date Table |
| DAX | Dynamic KPI aggregation, AOV calculation, YoY growth logic, Top-N filtering |
| Visualization | Custom color theming, interactive slicers, cross-filtering, container-based layout |

How It Works

The dashboard uses a quarter slicer at the top to dynamically filter all visuals — KPIs, charts, and maps update together based on the selected time period.
